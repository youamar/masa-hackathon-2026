# MASA Hackathon 2026 · R-Ignite — Submission Package

**Project:** Parametric Reinsurance for Agricultural Climate Risk in Malaysia & Indonesia
**Dataset:** World Bank World Development Indicators (Wide format, SDMX CSV)

## Setup

Tested on Python 3.12 (Windows) and Python 3.11+ (macOS/Linux).

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

No GPU, no external API keys, no internet required at runtime.

## Replication

Run the three steps in order from the project root.

### 1. ETL

```bash
python phase1_etl.py
```

Produces `cleaned_wdi_data.csv` (128 rows). Prints the first 5 rows and per-country non-null coverage for sanity checking.

### 2. Modelling & validation

```bash
python phase2_model.py
```

Produces `model_metrics.json`. Prints:
- Pearson correlation matrices (MYS, IDN) on the 33-year overlap.
- 2024 GHG out-of-sample backtest (MAPE: MYS 5.36%, IDN 10.58%).
- 2030 baseline GHG projection per country.

### 3. Interactive dashboard

```bash
python -m streamlit run app.py
```

Opens at `http://localhost:8501`. Sidebar exposes:
- Country selector (MYS / IDN).
- Stress slider: 2030 GHG emission increase (0–50%).
- Mitigation slider: parametric insurance adoption rate (0–100%).
- Agricultural GDP exposure (USD bn).
- **Advanced Actuarial Assumptions** expander: loss intensity per crop-index point and parametric payout efficiency.

The main panel renders KPI cards (2024 MAPE, baseline vs stressed 2030 GHG, cumulative loss avoided), the loss trajectory chart, the GHG path chart, and a model diagnostics block.

## Data lineage note

The handbook references the indicator code `EN.ATM.GHGT.KT.CE`. That code does not exist in the supplied SDMX wide file; we use **`WB_WDI_EN_GHG_ALL_MT_CE_AR5`** (Total greenhouse gas emissions excluding LULUCF, Mt CO2e under AR5), which is the closest "total GHG" series and ships with **2024 actuals** that enable our out-of-sample validation. This substitution and rationale is documented in §3 of `draft_report.md`.
